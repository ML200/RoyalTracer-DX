Dear ImGui is vendored from the official `v1.91.6-docking` tag:
https://github.com/ocornut/imgui/tree/v1.91.6-docking

Core files and the Win32 / DirectX 12 backends are copied from this release.
The existing project `imconfig.h` is retained. Multi-viewports are enabled by
the editor so panels can be dragged outside the main application window.
